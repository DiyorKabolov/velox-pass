# SC Tickets v2
 
Electronic ticketing system built with FastAPI + React + PostgreSQL.
 
## Stack
- **Backend**: FastAPI, SQLAlchemy, PostgreSQL, JWT
- **Frontend**: React 18, Vite, TanStack Query, Zustand, Tailwind CSS
 
## Structure
- `backend/` — FastAPI REST API
- `frontend/` — React SPA
